# MaplePath AI — Android MVP v0.2

تطبيق Android أصلي، محلي، تجريبي. لا يحتاج إلى خادم لاستخدام رفع CV ومطابقة وظائف CSV.

## من هاتف Android فقط: بناء APK عبر GitHub
1. أنشئ مستودع GitHub **خاصًا** (Private repository).
2. ارفع محتويات هذا المجلد إلى جذر المستودع (وليس ملف ZIP وحده).
3. افتح تبويب **Actions**، ثم اختر **Build Android APK** واضغط **Run workflow**. إن كان هذا أول تشغيل، فعّل Actions للمستودع.
4. بعد نجاح التشغيل افتح المهمة، ثم قسم **Artifacts**، وحمّل **MaplePath-AI-Android-debug-APK**.
5. فك ضغط ملف Artifacts، ثم افتح `app-debug.apk` على هاتفك وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.

> ملف APK غير مرفق في المشروع؛ يتم توليده من GitHub Actions. هذه نسخة debug للتجربة، وليست نسخة إنتاجية موقعة للنشر التجاري.

## ما يعمل
- اختيار عدة CV دفعة واحدة من ملفات الهاتف (PDF وDOCX وTXT) واستخراج النصوص القابلة للقراءة.
- إضافة مرشحين ووظائف يدويًا، واستيراد CSV متوافق مع المشروع السابق.
- عرض المطابقات بكلمات مشتركة، ومشاركة تقرير نصي عبر Android Share.
- حفظ البيانات محليًا على الجهاز.

## القيود
- لا يوجد بحث مباشر عن وظائف أو مزامنة أو إشعارات أو حسابات متعددة أو ذكاء اصطناعي سحابي في هذه النسخة.
- النسبة المعروضة هي **تداخل كلمات تقريبي** وليست احتمال الحصول على عمل أو أهلية الهجرة.
- حالة قبول المرشحين الدوليين تُعرض كما وردت في البيانات المستوردة، ولا يتم التحقق منها تلقائيًا.
- PDF المصور بدون نص لا يدعم OCR. استخراج DOCX بسيط وقد لا يحافظ على ترتيب النص.
- لا تدخل CV حقيقية أو معلومات حساسة قبل إضافة حماية بيانات وتدقيق أمني.
- ملفات الوظائف التجريبية وهمية بوضوح.

## CSV
الأعمدة المطلوبة: `title,company,province,description`.
الأعمدة الاختيارية: `city,url,source,posted_date,international_status,evidence,work_permit_support,noc,salary`.

## المرحلة القادمة
قاعدة بيانات مشفرة، حذف/تعديل المرشحين، حسابات وكالات، محرك وظائف مرخص، تحقق من أدلة التوظيف الدولي، محرك مطابقة متعدد اللغات، تقارير PDF، وتوقيع APK إصدار نهائي.
